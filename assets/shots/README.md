Adding new ones: send full-resolution exports in any format and they get
converted to WebP — 1600px wide for desktop screens, 1000px for phone screens,
quality 0.82.

The Plouma files came from design mockups with a phone bezel drawn in. That
bezel is trimmed and the corners are filled with the frame's panel colour
(#fffdf9), so the frame on the page is the only frame you see. Any new Plouma
export needs the same treatment; raw phone screenshots do not.
